# Phase 2 lighting handoff

Dark chrome #0D1117, surface #161B22, border #30363D, accent #2F6FEB.
Text #E6EDF3. Six pixel corners, generous spacing, 1280 × 800 default window.
Lighting: mode controls, 24 numbered logical zones in four rows, colour swatches,
nine firmware brightness steps, saved presets, and a persistent device status.
Zone positions are unverified; numbers describe controller IDs, not physical keys.
About explains device access and the deferred calibration and suspend work.
